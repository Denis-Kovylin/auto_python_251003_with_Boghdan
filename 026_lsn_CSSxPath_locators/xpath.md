# XPath Cheatsheet

| Тип                       | Пример                                             | Описание                                       |
|---------------------------|----------------------------------------------------|------------------------------------------------|
| По тегу                   | `//button`                                         | Все элементы `<button>`                        |
| По атрибуту               | `//input[@type='text']`                            | Поля ввода с `type="text"`                     |
| По ID                     | `//*[@id='login']`                                 | Любой элемент с ID "login"                     |
| По классу                 | `//*[contains(@class, 'btn')]`                     | Класс содержит "btn"                           |
| По тексту                 | `//a[text()='Login']`                              | Текст элемента точно "Login"                   |
| Частичный текст           | `//a[contains(text(), 'Log')]`                     | Текст элемента содержит "Log"                  |
| Комбинация условий        | `//input[@type='text' and @name='email']`          | Несколько условий одновременно                 |
| Потомок любого уровня     | `//form//input`                                    | Все `input`, вложенные в `form`                |
| Прямой потомок            | `//div/input`                                      | Только прямые потомки `<div>`                  |
| N-ый элемент              | `(//button)[3]`                                    | Третий `<button>` на странице                  |
| Последний элемент         | `(//li)[last()]`                                   | Последний `<li>` в списке                      |
| Родитель                  | `//input[@id='email']/..`                          | Родительский элемент                           |
| Сосед (following-sibling) | `//label[text()='Email']/following-sibling::input` | input рядом с label                            |
| Начинается с              | `//input[starts-with(@name, 'user')]`              | Атрибут name начинается с "user"               |
| Заканчивается на*         | `//input[ends-with(@name, 'name')]`                | *Только в XPath 2.0 — не всегда поддерживается |

📌 Быстрое копирование в DevTools:
ПКМ → Inspect → ПКМ на HTML-элементе → Copy → Copy **XPath**
